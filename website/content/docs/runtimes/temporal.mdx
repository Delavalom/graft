# Temporal Runtime

[Temporal](https://temporal.io) gives you per-step durability: every LLM call and every tool invocation runs as a separate activity, so a worker crash only reruns the failed step instead of the whole agent loop. The `temporal/` package wraps Temporal as a `graft.Runner`.

## Installation

```bash
go get github.com/delavalom/graft/temporal
```

Graft does **not** import `go.temporal.io/sdk`. Instead, `temporal.TemporalClient` is a small interface mirroring `*client.Client` — you inject your real SDK client.

## Two Sides: Client and Worker

A Temporal deployment has two processes:

1. **Worker** — registers the agent workflow and activities, executes LLM calls and tools.
2. **Client** — uses `TemporalRunner` to start the workflow and wait for the result.

### Client Side

```go
import (
    "time"

    "github.com/delavalom/graft"
    "github.com/delavalom/graft/temporal"
)

var temporalClient temporal.TemporalClient // your real *client.Client

runner := temporal.NewTemporalRunner(temporalClient,
    temporal.WithTaskQueue("ai-agents"),
    temporal.WithRetryPolicy(&temporal.RetryPolicy{
        MaxAttempts:        5,
        InitialInterval:    time.Second,
        BackoffCoefficient: 2.0,
        MaxInterval:        30 * time.Second,
    }),
)

agent := graft.NewAgent("durable-assistant",
    graft.WithInstructions("You are a helpful assistant running in a durable workflow."),
)

result, err := runner.Run(ctx, agent, []graft.Message{
    {Role: graft.RoleUser, Content: "Summarize the benefits of durable execution"},
})
```

### Worker Side

Import the `agentworkflow` sub-package and register the workflow + activities on your worker:

```go
import (
    "github.com/delavalom/graft/provider/openai"
    "github.com/delavalom/graft/temporal/agentworkflow"
    "go.temporal.io/sdk/worker"
)

model := openai.New(
    openai.WithAPIKey(os.Getenv("OPENROUTER_API_KEY")),
    openai.WithBaseURL("https://openrouter.ai/api/v1"),
    openai.WithModel("anthropic/claude-sonnet-4.6"),
)
models := agentworkflow.NewSingleModelProvider(model)

toolRegistry := agentworkflow.NewToolRegistry()
toolRegistry.Register(myTool1, myTool2)

w := worker.New(temporalClient, "ai-agents", worker.Options{})
agentworkflow.RegisterAgentWorkflow(w)
agentworkflow.RegisterAgentActivities(w, models, toolRegistry)

w.Run(worker.InterruptCh())
```

Each LLM call runs as a `GenerateActivity`; each tool call runs as a `ToolActivity`. On worker crash, Temporal replays completed activities from event history and resumes from the last checkpoint.

The [`examples/temporal/`](https://github.com/delavalom/graft/tree/main/examples/temporal) directory has two sub-packages:

- [`client/`](https://github.com/delavalom/graft/tree/main/examples/temporal/client) — runnable workflow-dispatch example using an in-process demo client.
- [`worker/`](https://github.com/delavalom/graft/tree/main/examples/temporal/worker) — registration pattern for a real Temporal worker.

## Runner Options

| Option | Purpose |
|--------|---------|
| `WithTaskQueue(string)` | Temporal task queue the workflow runs on |
| `WithWorkflowID(string)` | Deterministic workflow ID (dedupe-friendly) |
| `WithRetryPolicy(*RetryPolicy)` | Activity-level retry policy |

## Activities as Tools

Expose an existing Temporal activity as a Graft tool via `ActivityAsTool`:

```go
tool := temporal.ActivityAsTool(
    "fetch-invoice",
    "Fetch an invoice by ID.",
    schema,
    executor, // your ActivityExecutor
    temporal.WithActivityConfig(&temporal.ActivityConfig{ /* ... */ }),
)
```

Use this when tools need to participate in the same durable history as the agent loop.

## Handoffs and Signals

- **Handoffs** across agents are modeled with `ContinueAsNew`, carrying the handoff target's instructions and tools into a fresh workflow run.
- **Human-in-the-loop** flows listen for Temporal signals on an approval channel, pausing the agent until a signal arrives.

## When to Choose Temporal

- You need per-step durability and deterministic replay.
- You want signals for human approval gates.
- You already run Temporal for other workloads and want a single engine.
