# Providers

Every LLM provider in Graft implements the same `LanguageModel` interface:

```go
type LanguageModel interface {
    Generate(ctx context.Context, params GenerateParams) (*GenerateResult, error)
    Stream(ctx context.Context, params GenerateParams) (<-chan StreamChunk, error)
    ModelID() string
}
```

This means you can swap providers without changing your agent code. All providers use raw `net/http` — no external SDKs.

## Available Providers

| Provider | Package | Models |
|----------|---------|--------|
| OpenAI | `provider/openai` | GPT-4o, GPT-4o-mini, o1, o3, etc. |
| Anthropic | `provider/anthropic` | Claude Sonnet, Claude Opus, Claude Haiku |
| Google | `provider/google` | Gemini 2.0 Flash, Gemini 2.5 Pro |
| AWS Bedrock | `provider/bedrock` | Claude, Titan, Llama, Mistral via Converse API |
| OpenAI-compatible | `provider/openai` | OpenRouter, Ollama, LM Studio, vLLM |

## Choosing a Provider

- **Direct API** — [OpenAI](/docs/providers/openai), [Anthropic](/docs/providers/anthropic), [Google](/docs/providers/google). Simplest path when you already have a vendor API key.
- **AWS-native** — [Bedrock](/docs/providers/bedrock). Uses SigV4 and the AWS Converse API; good fit inside AWS environments and for Claude/Titan/Llama/Mistral under a single IAM policy.
- **OpenAI-compatible** — [OpenRouter, Ollama, LM Studio, vLLM](/docs/providers/openai#openai-compatible-apis). Reuse the OpenAI provider with `WithBaseURL` for local models, gateways, and multi-model aggregators.
- **Custom** — [Write your own](/docs/providers/custom). Implement `LanguageModel` for internal gateways or vendors not listed above.

## Provider Middleware

Wrap any provider with middleware using `provider.Chain`:

```go
import "github.com/delavalom/graft/provider"

model := openai.New(openai.WithAPIKey("sk-..."))
wrapped := provider.Chain(model, provider.WithLogging(logger))
```

## Provider Router

Route between multiple providers for fallback or load balancing:

```go
router := provider.NewRouter(
    provider.WithFallback(primaryModel, fallbackModel),
)
// or
router := provider.NewRouter(
    provider.WithRoundRobin(model1, model2, model3),
)
```
