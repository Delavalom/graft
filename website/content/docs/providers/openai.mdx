# OpenAI Provider

The OpenAI provider works with OpenAI's API and any OpenAI-compatible endpoint.

## Installation

```bash
go get github.com/delavalom/graft/provider/openai
```

## Basic Usage

```go
import "github.com/delavalom/graft/provider/openai"

model := openai.New(
    openai.WithAPIKey(os.Getenv("OPENAI_API_KEY")),
)
```

## Options

```go
model := openai.New(
    openai.WithAPIKey("sk-..."),
    openai.WithModel("gpt-4o"),          // Default model
    openai.WithBaseURL("https://..."),    // Custom endpoint
    openai.WithHeaders(map[string]string{ // Custom headers
        "X-Custom": "value",
    }),
)
```

## OpenAI-Compatible APIs

### OpenRouter

```go
model := openai.New(
    openai.WithAPIKey(os.Getenv("OPENROUTER_API_KEY")),
    openai.WithBaseURL("https://openrouter.ai/api/v1"),
    openai.WithModel("anthropic/claude-sonnet-4-20250514"),
)
```

### Ollama (Local)

```go
model := openai.New(
    openai.WithBaseURL("http://localhost:11434/v1"),
    openai.WithModel("llama3"),
)
```

### LM Studio

```go
model := openai.New(
    openai.WithBaseURL("http://localhost:1234/v1"),
    openai.WithModel("local-model"),
)
```
