# Google Gemini Provider

The Google provider uses the Generative Language API for Gemini models.

## Installation

```bash
go get github.com/delavalom/graft/provider/google
```

## Basic Usage

```go
import "github.com/delavalom/graft/provider/google"

model := google.New(
    google.WithAPIKey(os.Getenv("GOOGLE_API_KEY")),
)
```

## Options

```go
model := google.New(
    google.WithAPIKey("AIza..."),
    google.WithModel("gemini-2.0-flash"),
)
```

## Supported Models

| Model | ID |
|-------|-----|
| Gemini 2.5 Pro | `gemini-2.5-pro` |
| Gemini 2.0 Flash | `gemini-2.0-flash` |
| Gemini 2.0 Flash Lite | `gemini-2.0-flash-lite` |
